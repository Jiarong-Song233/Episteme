# 复用决策记录 0011：取消关联

调查日期：2026-11-13。

## 目标能力

0008 和 0010 让本人把一条理解关联到学习目标，之后答错会问到它。但关联错了没法取消，这一条之后的每次答错都会对一条不相干的理解提出怀疑，审阅负担只增不减。

目标：本人能取消自己做的关联。取消后答错不再问到这条理解，原来的记录还在。

## 本仓已有能力

| 来源 | 已有实现 | 用法 |
| ---- | ---- | ---- |
| `evidence.ts` 的学习证据 | 只追加，每条有 `seq` 和时间，按顺序读 | 加一种 `unlink` 证据；读的时候按顺序处理，取消之后这条关联不算，再关联又算 |
| `objectivesOf` 的 `candidates` | 目标关联到的候选和现在的节点 | 每条标出是不是本人自己关联的（`tiedByPerson`） |
| `doubt.ts` 的 `proposeDoubt` | 只对目标的 `candidates` 提怀疑 | 不改，取消后自然不再提出 |
| 会话列表 | 每个计划下的证据事件 | 取消也作为一个事件列出，写明取消的是哪一条 |
| 场景路由的权限清单 | 不在 `route-access.ts` 里的路由只有本人能用 | 新路由不加进清单，Agent 不能取消 |

## 外部做法

| 项目 | 许可证 | 做法 |
| ---- | ---- | ---- |
| [Moodle Competencies](https://docs.moodle.org/402/en/Competencies) | GPL-3.0 | 教师可以在课程里添加和移除能力，也能看到哪些能力关联了哪些活动 |
| [Canvas：把学习成果对齐到题库](https://community.canvaslms.com/docs/DOC-1906)（沿用 0008 的来源） | AGPL-3.0 | 对齐由教师维护 |

采用的是“关联由设定它的人维护，可以撤掉”这一点。没有查到 Moodle 移除关联后已有证据怎么处理，所以这一点没有参照，按本仓“证据只追加”的规则自己定：不删除旧记录，追加一条取消。

## 决策

| 项 | 内容 |
| ---- | ---- |
| 复用选项 | 参考后重写，在已有的证据读法上加一种事件 |
| 不引入依赖 | 不需要 |
| 不删记录 | 追加 `unlink` 证据，原来的关联记录不动 |
| 只能取消自己的 | Agent 记下的关联不能在这里取消，拒绝码 `not_yours`。它跟着 Agent 提出的候选走，本人可以在确认页拒绝那条候选 |
| 已经提出的怀疑 | 不撤回。它在等本人决定，本人可以直接拒绝 |
| 再次关联 | 允许，从那以后又算 |

## 成本和风险

- 成本：`evidence.ts` 一个读法函数和一个字段；`routes.ts` 一个路由；概览页一个按钮；三个测试。
- 风险：同一条候选如果既被 Agent 又被本人关联，取消会把两者都去掉。现在本人关联时，如果候选已经关联，会直接返回“已关联”，不会再记一条，所以这种情况不会出现。
- 验证：`tests/practice-doubt.test.ts` 的“taking a tie back”，`tests/host-learning.test.ts` 的 Agent 关联不能取消；本机在图谱副本上走一遍。
