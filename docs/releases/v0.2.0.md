# Episteme v0.2.0：学习工作台

v0.2.0 是第二个开发预览版（Developer Preview）。它第一次可以不经命令行使用：装好桌面程序，在工作台里上传材料、提问、审阅候选、查看自己的理解，再把 Agent 接进来。它仍然面向愿意试用早期软件的人，不是稳定版本。

完整的改动列表见 [CHANGELOG](../../CHANGELOG.md#020---2026-11-09)，安装见 [install.md](../install.md)。

## 这一版有什么

- **学习工作台**：空间、对话、材料、学习计划、待确认、我的理解，各有自己的页面和地址；对话可以从任一轮次分叉，按树排列。
- **桌面程序和一行命令安装**：Windows、macOS（Apple 芯片）和 Linux 安装包，自带 Node 运行环境；安装脚本先校验 `SHA256SUMS` 再安装。安装包**没有代码签名**，系统会提示来源未知。
- **接入 Agent**：工作台找出这台电脑上装了哪些 Agent（Claude Code、Codex 等二十多种），一键接入或断开；也支持 JSON 插件描述的 Agent，插件声明的程序只在本人确认后运行。
- **在工作台里设置模型**：DeepSeek、OpenAI、OpenRouter、本机 Ollama 或任何兼容 OpenAI 接口的服务，保存前先试答一次。
- **语义检索（可选，默认关闭）**：设置嵌入服务后，换个说法提问也能召回；出错时退回关键词检索并在回答里说明。
- **存储只用 SQLite**：一个图谱一个文件；旧的 JSONL 图谱要先用 `pnpm serve graph convert` 转换。

没有变的原则：Agent 只能读取和提出候选，确认只能由本人在工作台里做；图谱只追加，确认过的理解保留它的原话来源。

## 升级时要注意

1. **旧的 JSONL 图谱和第 1 版 SQLite 图谱不能直接打开。** 服务会拒绝并且不改动文件。用 `pnpm serve graph convert <旧图谱> <新图谱>` 转成新文件，旧文件只读。默认图谱改为 `~/.episteme/learn.db`。
2. **需要 Node 22 或更高版本**（只影响从源码运行；桌面程序自带运行环境）。
3. **`summary` 字段改为英文。** `recall`、`recallSummary` 和 `progress` 的中文摘要移到新字段 `summaryZh`。直接读 `summary` 显示中文的 SDK 或 REST 调用方要改读 `summaryZh`。MCP 的文本回答不受影响。
4. **“已站稳”在召回里变严了。** 学习场景要求把握程度和表达能力都在中等以上，和进度页一致。以前只有一个维度达标的节点，在召回里不再标为已站稳。
5. **Agent 令牌不能再做场景里的高影响操作**（删除材料、归档或改名空间），只能用提议类操作。依赖旧行为的脚本要改用本人的令牌。

- **没有真人学习者用过。** 学习效果、审阅负担都没有数据。

- **安装包在干净机器上的安装**：以 CI 构建和本机安装为准，没有在每个平台的全新系统上试过。

## 已知限制

1. **没有 LICENSE 文件。** 许可证由仓库所有者另行决定；在此之前，这份代码没有授予任何使用许可。
2. **安装包没有代码签名。**
3. **数据以明文保存在本地。** 图谱、材料和导出文件都没有加密；服务只监听本机地址，不要暴露到网络上。导出文件是整个图谱，多人使用时包含其他人的内容。
4. **本机上的任何程序都能往本地图谱里添加内容。** 本地模式下读取、提议、新建空间和材料不需要凭证；删除、归档、改名需要本人的令牌。
5. **旧式中文 PDF 读不出。** 中文字体未嵌入、用预定义 CMap（如 `UniGB-UCS2-H`）的文件会被拒绝并说明原因；现在的工具生成的中文 PDF 能读。扫描件不支持，需要先做 OCR。
6. **被拒绝的候选换一种说法仍可能再次出现**：相近判断是词覆盖，不理解语义。
7. **模型预算只按单次运行计**，重启后清零。

## 数据格式

| 内容 | 格式 |
| --- | --- |
| 图谱 | 一个 SQLite 文件（`user_version = 2`），节点、边、状态事件以及旁边的建议、材料、对话、场景记录都在里面 |
| 模型设置 | 图谱旁边的 `model.json`（Linux 和 macOS 上权限 `0600`） |
| 导出 | `pnpm workbench export` 生成的 JSON，带来源、构建、版本和校验和；只导入到新文件 |

本版不改写已有记录，也不需要迁移：已经是第 2 版 SQLite 的图谱直接打开。
