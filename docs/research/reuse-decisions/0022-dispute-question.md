# 复用决策记录 0022：本人标记“这道题有问题”

日期：2026-11-16。

## 要解决的问题

选择题的正确选项由模型出题时给出，没有人校对；填空题挖掉的词也可能挖得不对。答案键错了时，人答对了也被记成“没答对”，而且会影响三个地方：

- 正确率；
- 复习建议（隔一天再看）；
- 学习证据（答错还会提出一条“怀疑”）。

人没有办法说“这道题本身有问题”。

## 本仓已有能力

- 每次作答是一条场景记录 `attempt/<id>`，记着题目、答案键、作答和判定。
- 场景记录每次写入都追加一个版本，旧版本不丢。
- 场景路由默认只有本人能用，Agent 的凭据会被拒绝（`route-access.ts`）。

## 参考的做法

| 做法 | 说明 |
| ---- | ---- |
| [Anki](https://docs.ankiweb.net/editing.html) 的标记（Flag）和挂起（Suspend） | 用户自己把有问题的卡片标出来或挂起，挂起的卡不再出现，复习记录保留 |
| [Moodle 测验](https://docs.moodle.org/en/Quiz_reports)的重新评分 | 题目有错时，教师修改后重新评分，原作答保留 |

这里没有教师。答案键错没错，只有学习者本人能判断，所以由本人标记。

## 决定

- 新路由 `POST /practice/dispute {attempt, disputed}`，只有本人能用。只能标记答过的题。`disputed: false` 撤回标记。
- 标记单独存为 `dispute/<attempt>`，不改作答记录本身。
- 标记了的作答，在下面三处都不计入：
  - 学习状态的正确率和模型估计；
  - 复习建议；
  - 学习证据（成果页里的作答事件）。
- 学习状态多返回一个 `disputed` 数。页面在正确率旁说明“答案由模型从材料里出，可能有错”，有标记时写明几道不计入。
- 计划的步骤列表里，答过的题显示结果（答对、没答对、模型估计……），旁边是“这道题有问题”或“撤回标记”。
- 其他作答的证据编号不变：先编号，再剔除。

## 局限

- 标记不会撤回答错时已经提出的“怀疑”提议。它还在待确认里，要人自己驳回。
- 不能改答案键，只能整题不计入。
- 题目入口在计划的步骤列表里，默认是折叠的，不够显眼。
- 只有服务测试和本地页面操作，没有浏览器自动化测试。
