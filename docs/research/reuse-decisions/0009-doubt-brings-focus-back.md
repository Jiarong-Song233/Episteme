# 复用决策记录 0009：被怀疑的理解回到学习计划

调查日期：2026-11-13。外部做法来自当日读到的社区文档和用户指南，未读到 Anki 官方手册的对应段落。

## 目标能力

速通计划会跳过本人已确认过的重点。0007 和 0008 让答错能问到本人的理解，本人同意后，这条理解的“冲突”记为“疑似”。但计划仍把它当成已经理解，所以下一次学习恰好跳过了本人自己同意可能有问题的那个重点。

目标：本人记下怀疑（`suspected` 或 `open`）的理解，不再让计划跳过对应重点；怀疑解决（`resolved`）后照常跳过。

## 本仓已有能力

| 来源 | 已有实现 | 用法 |
| ---- | ---- | ---- |
| `plans.ts` 的 `layOut` | 按“已理解”的说法跳过重点 | 不改，只改传进去的“已理解”列表 |
| `learning.ts` 的计划生成 | 取空间里仍持有的理解作为“已理解” | 去掉本人记下怀疑的那些 |
| 学习场景的 `conflict` 维度 | none / suspected / open / resolved | 直接读本人记下的级别 |
| `doubt.ts` | 已有“已经在怀疑”的判断，用来避免重复提议 | 抽成 `isDoubted`，两处共用同一个定义 |
| Application 的 `progress()` | 未解决冲突已经算作需要关注 | Agent 侧已有，不改 |

## 外部做法

| 项目 | 许可证 | 做法 |
| ---- | ---- | ---- |
| Anki（[社区整理的学习说明](https://noobj2.github.io/anki-manual/studying.html)、[失误后间隔的说明](https://eshapard.github.io/anki/anki-new-interval-after-a-lapse.html)） | AGPL-3.0 | 已毕业的卡片答错（lapse）后进入重新学习，走完重新学习步骤再回到复习 |

采用的是“已掌握的东西出了错，就回到学习里”这一点。不同的是：Anki 一答错就自动重学，这里只在本人确认怀疑之后才改，等待确认的怀疑不影响计划。

## 决策

| 项 | 内容 |
| ---- | ---- |
| 复用选项 | 参考后重写，改动在已有的计划生成里，一个过滤条件 |
| 不引入依赖 | 不需要 |
| 只看本人记下的 | 等待确认的提议不算，和“确认前理解不变”一致 |
| 解决后 | `resolved` 的理解重新算作已理解，重点照常跳过 |
| 已经生成的计划 | 不改。只影响之后新生成的计划 |

## 成本和风险

- 成本：`learning.ts` 一个过滤；`doubt.ts` 导出一个判断；两个测试。
- 风险：跳过重点用的是说法相似度。理解的说法和重点不像时，本来就不会跳过，这次改动不影响那种情况。
- 验证：`tests/practice-doubt.test.ts` 的“a later plan”；本机在图谱副本上走一遍。
